AUTH SYSTEM — FULL LOGIC
═══════════════════════════════

STEP 1 — Google Login:
- User clicks "Login with Google"
- Google OAuth redirects back
- User profile saved in db.json with approved: false

STEP 2 — Access Code Gate:
- After Google login, if user.accessGranted is false:
  - Show a code entry screen
  - User must enter the exact code: muneebrahman56
  - If correct: set user.accessGranted = true in db
  - If wrong: show error "Invalid access code"
  - Once approved, they never see this screen again on future logins

STEP 3 — App Access:
- Only users with accessGranted: true can access the main app
- All other routes redirect to login

Routes:
GET  /auth/google           — start Google OAuth
GET  /auth/google/callback  — OAuth callback
GET  /auth/logout           — destroy session, redirect to /
GET  /api/me                — return current user or 401
POST /api/verify-code       — accept { code }, verify against MASTER_ACCESS_CODE
GET  /                      — serve index.html (protected, must be logged in + approved)

Middleware: 
function requireAuth(req, res, next) {
  if (!req.user) return res.redirect('/login.html');
  if (!req.user.accessGranted) return res.redirect('/verify.html');
  next();
}

WhatsApp flow in POST /start:
1. Clean phone number: remove all non-digits
2. Emit step 0 active
3. Initialize WhatsApp client with LocalAuth + puppeteer args
4. Call client.initialize()
5. Call client.requestPairingCode(phone) — MUST be called after initialize()
6. Emit paircode event with the code
7. Wait for 'ready' event (timeout 120 seconds, reject on timeout or auth_failure)
8. Emit step 1 done
9. await delay(800)
10. Emit step 2 done
11. Process image with Sharp:
    - Resize to 1080x1440 fit:'contain' background black
    - Save to uploads/processed_timestamp.jpg
12. Emit step 3 done
13. Set profile picture: const media = MessageMedia.fromFilePath(processedPath)
    await client.setProfilePicture(media)
14. Emit step 4 done
15. await delay(1000)
16. Emit step 5 done
17. await delay(600)
18. Emit success
19. Send WhatsApp message to self (owner's number):
    await client.sendMessage(phone + '@c.us', '🤖 Fullscreen DP AI: Bot connected and profile picture updated successfully! Bot is now disconnecting.')
20. await client.destroy()
21. Delete both image files (original + processed)

Error handling:
- Wrap entire flow in try/catch
- On error: emit 'error' { message: err.message }
- Destroy client if exists
- Delete uploaded files

IMPORTANT:
- res.json({ success: true }) BEFORE starting async WhatsApp process
- The WhatsApp process runs in background after response sent
- Use let activeClient = null to track and destroy previous sessions

CRITICAL RULES — DO NOT SKIP

8. express-session must come before passport.initialize()
9. Google OAuth callback URL must match exactly: APP_URL + /auth/google/callback
10. Access code comparison must be exact string match: code === process.env.MASTER_ACCESS_CODE
11. All 3 HTML files must be in /public folder
12. requireAuth middleware on GET / route
13. socket.io CDN: https://cdn.socket.io/4.7.5/socket.io.min.js
