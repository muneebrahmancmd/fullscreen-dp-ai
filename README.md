# Fullscreen DP AI

AI-powered tool for fullscreen WhatsApp display pictures (DP): view and set DPs without the usual crop.

**Live Demo:** https://fullscreen-dp-ai--munaseedance.replit.app

Whenever we set a profile picture on WhatsApp, WhatsApp crops it into a small square and the full photo is lost. I made a tool for this problem. With Fullscreen DP AI, you connect your WhatsApp to the agent and upload the picture you want. The agent automatically sets it as your profile picture in full 9:16 size, without any crop, without any scam tricks, and without any modded or fake WhatsApp apps. Your full picture, exactly the way you wanted it.

## Features

- Set your WhatsApp profile picture in full 9:16 size, without any crop cutting your photo.
- Connect your WhatsApp to the agent in the app and let the agent set the picture for you.
- Upload the picture you want and it is set automatically, no manual editing needed.
- View and download profile pictures in full HD.
- Google login, so you can sign in fast with your Google account.
- Free to use and fully open source under the MIT license.

## How it works

1. Connect your WhatsApp to the agent in the app.
2. Upload the picture you want as your profile picture.
3. The agent sets it for you, fullscreen, without any crop.

## Getting Started

This project is a TypeScript monorepo using pnpm workspaces (originally built on Replit).

```bash
git clone https://github.com/muneebrahmancmd/fullscreen-dp-ai.git
cd fullscreen-dp-ai
pnpm install
```

Then check `package.json` and `replit.md` for the available run scripts for each workspace (API server and web app).
